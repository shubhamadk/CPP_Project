# 🏨 Hotel Management System in C++

A console-based Hotel Management System written in C++. This project helps manage hotel operations such as customer check-ins, check-outs, room allocation, and billing, with data stored in local files.

## 🚀 Features

- Add new customers
- Assign and track room occupancy
- Perform check-in and check-out
- Generate and manage bills
- Track payments
- Persistent data storage using `.dat` files

## 🛠️ Technologies

- Language: C++
- File I/O for persistent storage
- Object-Oriented Design (Classes: `Customer`, `Room`, `Bill`, `FileManager`, `HotelSystem`)

## 🗂️ Project Structure
CPP_Project
├── main.cpp # Main C++ source file
├── customers.dat # Customer data (auto-generated)
├── rooms.dat # Room status data (auto-generated)
├── bills.dat # Billing records (auto-generated)
├── config.dat # Internal ID tracking
└── README.md # Project documentation

## 🧰 Requirements

- C++11 or later
- Any C++ compiler (e.g., `g++`, `clang++`)
